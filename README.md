# 바이브코딩 해커톤 - 팀 발표 제출 양식

## 1. 팀명 / 팀원

- 팀명:09_frontAce
- 팀원 (2명): 이지원 주명현

## 2. 한 줄 소개
우울감과 정서적 어려움을 겪는 사람들 및 본인의 감정을 기록하고 싶은 사람들을 위한 따뜻한 파스텔 톤의 감정 일기 웹앱으로, 월간 캘린더에 기분을 기록하고 AI와 함께 감정을 정리할 수 있는 공간입니다.

## 3. 선정 이유 / 해결하려 한 문제

> 현대인들이 겪는 우울감과 감정 변화를 객관적으로 관찰하고 이해할 수 있는 안전하고 편리한 공간이 필요합니다.
> MoodMap은 감정 상태를 진단하는 도구가 아닌, 감정을 부드럽게 관찰하고 자기 이해를 돕는 감정 관찰 도구로서 사용자의 심리적 회복을 지원합니다.



## 4. 핵심 기능

- 기능 1: 감정 캘린더 - 2021년부터 현재까지의 월간 캘린더에서 5가지 감정(기쁨, 평온, 불안, 무기력, 우울함)을 색상으로 시각화하여 감정 흐름을 한눈에 파악
- 기능 2: 감정 체크인 - 우울감 정도, 무기력/피로, 집중력, 수면 패턴, 식욕 변화 등을 세부 기록하고 오늘의 가장 힘들었던/행복했던 순간을 자유롭게 입력
- 기능 3: AI 프롬프트 생성 - 기록한 감정 데이터를 ChatGPT/Gemini 형식의 자동 프롬프트로 변환하여 AI와 함께 감정을 정리하고 위로받기

## 5. 사용 기술 스택

- 언어 / 프레임워크: HTML5, CSS3, Vanilla JavaScript
- 기타 도구: Git/GitHub, 브라우저 기반 로컬 스토리지 활용

## 6. AI 활용 포인트

>GitHub Copilot을 다음과 같이 활용했습니다:

1. 에이전틱 개발 방식: 사용자의 복잡한 디자인 요청(파스텔 톤, 감정별 색상 체계, 인터랙티브 효과)을 한국어 자연어로 받아서 자동으로 CSS/JavaScript 구현
2. 반복적 리팩토링: 초기 디자인에서 사용자의 피드백(달력 셀 크기 조정, 그라데이션 제거, 버튼 활성화 상태 개선 등)을 받아 여러 번 코드 수정
3. 코드 자동 완성: 캘린더 렌더링 로직, 감정별 이모티콘 필터, 토스트 알림 등을 효율적으로 구현
4. 다중 파일 동시 수정: 메인, 체크인, AI 대화, 대시보드, 요약 페이지의 CSS를 일관성 있게 유지하기 위해 동시 수정 지원
